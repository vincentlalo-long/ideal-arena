# Ideal Arena - Web Frontend

Modern React + TypeScript + Tailwind CSS web dashboard for the Ideal Arena Multi-Agent Judger Platform.

## Features
- **Match Replay Visualizer**: Interactive round-by-round replay playback, payoff curves, action tapes, and live simulation.
- **Tournament Dashboard**: Multi-agent round-robin tournament runner and real-time Leaderboard.

## Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
