\section{Overview and Security Principles}

Algorithm Arena executes arbitrary, user-submitted source code and compiled binaries from untrusted external participants. To ensure competitive fairness, benchmark integrity, and host system security, the platform operates under a strict \textbf{Zero-Trust Sandbox Model}.

\subsection{Core Principles}
\begin{enumerate}
    \item \textbf{Strict Hermetic Isolation:} Untrusted code cannot access network interfaces, host filesystem structures, hardware devices, or sibling container memory.
    \item \textbf{Absolute Determinism:} Hardware clocks, thread scheduling, and PRNG seeds are virtualized or constrained to produce identical execution trajectories on identical inputs.
    \item \textbf{Hard Multi-Tier Resource Limits:} Exact CPU, memory, time, and file descriptor bounds are enforced at the Linux kernel level via cgroups v2 and seccomp-bpf.
\end{enumerate}

\section{Sandbox Isolation Architecture}

\subsection{Linux Kernel Namespaces}
Each submission instance is encapsulated within six isolated kernel namespaces:
\begin{itemize}
    \item \textbf{Mount (CLONE\_NEWNS):} Mounts a minimal, read-only rootfs containing only language runtime essentials.
    \item \textbf{PID (CLONE\_NEWPID):} Isolates the process table; the participant controller is PID 1.
    \item \textbf{Network (CLONE\_NEWNET):} Disconnects all physical and virtual network interfaces.
    \item \textbf{IPC (CLONE\_NEWIPC):} Blocks host shared memory segments and semaphores.
    \item \textbf{UTS (CLONE\_NEWUTS):} Isolates host system hostname and domain information.
    \item \textbf{User (CLONE\_NEWUSER):} Maps container root to an unprivileged host UID.
\end{itemize}

\subsection{Seccomp-BPF Syscall Filtering}
A strict Berkeley Packet Filter (BPF) intercepts all system calls executed by user code:
\begin{itemize}
    \item \textbf{Allowed Syscalls:} \texttt{read}, \texttt{write} (standard pipes only), \texttt{futex}, \texttt{mmap}, \texttt{brk}, \texttt{clock\_gettime}, \texttt{exit\_group}.
    \item \textbf{Blocked Syscalls (Instant Termination):} \texttt{fork}, \texttt{vfork}, \texttt{clone}, \texttt{execve}, \texttt{socket}, \texttt{connect}, \texttt{bind}, \texttt{ptrace}, \texttt{kill}, \texttt{chroot}, \texttt{open} (write-mode).
\end{itemize}

\section{Multi-Language Runtime Toolchains}

The execution platform provides standardized language toolchains:

\subsection{Python 3 Runtime}
\begin{itemize}
    \item \textbf{Interpreter:} CPython 3.10+ (64-bit Linux).
    \item \textbf{Pre-installed Numerical Packages:} \texttt{numpy}, \texttt{scipy}.
    \item \textbf{Prohibited Standard Modules:} \texttt{os}, \texttt{sys}, \texttt{subprocess}, \texttt{socket}, \texttt{ctypes}, \texttt{threading}, \texttt{multiprocessing} (blocked via import hooks and seccomp filters).
\end{itemize}

\subsection{C++ Runtime}
\begin{itemize}
    \item \textbf{Compiler:} GCC 13+ / Clang 17+ with flags:
    \begin{lstlisting}[language=bash]
    g++ -O3 -std=c++20 -static -fno-rtti -Wall -Wextra -s submission.cpp -o controller
    \end{lstlisting}
    \item \textbf{Standard Libraries:} Full ISO C++20 standard library (STL).
\end{itemize}

\subsection{Rust Runtime}
\begin{itemize}
    \item \textbf{Toolchain:} Rust Stable (1.75+).
    \item \textbf{Compilation Command:} \texttt{cargo build --release --target x86\_64-unknown-linux-musl}.
\end{itemize}

\subsection{Java Runtime}
\begin{itemize}
    \item \textbf{JVM / JDK:} OpenJDK 21 LTS (64-bit).
    \item \textbf{Execution Flags:}
    \begin{lstlisting}[language=bash]
    java -XX:+UseSerialGC -Xms32m -Xmx220m -Dfile.encoding=UTF-8 -jar submission.jar
    \end{lstlisting}
    \item \textbf{Security Policy:} Custom Java SecurityManager / JVM agent blocking unauthorized reflective access and network sockets.
\end{itemize}

\subsection{Go Runtime}
\begin{itemize}
    \item \textbf{Compiler:} Go 1.22+ (gc toolchain).
    \item \textbf{Compilation Command:}
    \begin{lstlisting}[language=bash]
    CGO_ENABLED=0 go build -ldflags="-s -w" -o controller main.go
    \end{lstlisting}
    \item \textbf{Characteristics:} Statically linked pure binary with minimal memory footprint.
\end{itemize}

\section{Inter-Process Communication (IPC) Protocol}

The platform executes matches via a \textbf{Driver-Worker Architecture}:

\begin{figure}[htbp]
\centering
\begin{lstlisting}[language=bash]
[ Arena Arbiter Engine ]
        |
        |--- (Anonymous Unix Pipe / Shared Memory)
        |
        v
[ Sandbox Worker (seccomp + namespaces) ]
   +-- Controller Instance (User Code)
\end{lstlisting}
\caption{Arena Arbiter and Sandbox Worker communication channel.}
\label{fig:ipc_arch}
\end{figure}

\begin{enumerate}
    \item \textbf{Handshake:} Arbiter sends \texttt{RESET(seed=0x3F8A)} over stdin. Controller responds with \texttt{ACK}.
    \item \textbf{Step Dispatch:} Arbiter transmits JSON/binary observation packet.
    \item \textbf{Action Reply:} Controller writes integer action token within 10ms.
    \item \textbf{Watchdog Enforcement:} If timeout expires, Arbiter forcefully SIGKILLs the sandbox worker.
\end{enumerate}
